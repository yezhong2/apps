Formula Parser

How to use Formula Parser:
  • Enter any mathematical expression with variables x, y, z
  • Supported operations: +, -, *, /, ^, sin, cos, tan, log, sqrt, abs
  • Special symbols: π (pi), e (Euler's number)
  • Examples: x^2 + 2*x + 1, sin(x) + cos(y), sqrt(x^2 + y^2)
  • The parser will simplify, evaluate with sample values, and show step-by-step breakdown

Algebra Solver

How to use Algebra Solver:
  • Enter equations with one variable (x)
  • Supported: linear equations, quadratic equations
  • Format: ax + b = c, ax^2 + bx + c = 0
  • The solver will find real solutions and show solving steps

Integral Calculator

How to use Integral Calculator:
  • Enter integral expressions with variable x
  • Supported: power functions, trigonometric functions, exponential functions
  • Format: integrate f(x) dx, integrate f(x) dx from a to b
  • For definite integrals, include limits (e.g., "from 0 to 1")
  • The calculator will show the antiderivative and evaluation steps

Limit Calculator

How to use Limit Calculator:
  • Enter limit expressions with variable x
  • Supported: direct substitution, factoring, special limits
  • Format: limit of f(x) as x approaches a
  • Examples: (x^2 - 1)/(x - 1), sin(x)/x
  • The calculator will evaluate the limit and show solution steps

Math Theorem Search

How to use Theorem Search:
  • Search for mathematical theorems by keywords
  • Try terms: Pythagorean, Fundamental Theorem, Law of Large Numbers
  • Each result includes theorem statement and proof
  • Use the copy button to save theorem information
