Code Style Guide

Naming Conventions
Use descriptive names that explain the purpose of variables, functions, and classes.
Good:
calculateTotalPrice(items)
Avoid:
calc(items)
Indentation
Use consistent indentation (2 or 4 spaces) to improve code readability.
Good:
function example() {
  return true;
}
Avoid:
function example() {
return true;
}
Comments
Write meaningful comments that explain why code does something, not what it does.
Good:
// Using Fisher-Yates algorithm for unbiased shuffling
function shuffle(array) {
  // Implementation
}
Avoid:
// This function shuffles the array
function shuffle(array) {
  // Shuffle code
}
