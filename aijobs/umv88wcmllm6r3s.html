以下是一个简单的Python函数，用于计算一个非负整数的阶乘：

```python
def factorial(n):
    if n == 0:
        return 1
    else:
        return n * factorial(n - 1)

# 示例使用
number = 5
result = factorial(number)
print(f"{number}的阶乘是：{result}")
```

这个函数使用递归的方式来计算阶乘。当传入的参数`n`等于0时，阶乘的值为1（因为0的阶乘定义为1）。否则，函数会递归地调用自身来计算`n * (n-1) * (n-2) * ... * 1`。需要注意的是，递归深度过大可能会导致栈溢出错误，因此在实际应用中需要考虑递归深度的限制。
