**Definición:** Un test es una evaluación o examen que se realiza para medir habilidades, conocimientos o características de alguien.

**Análogo:** Imagina que tienes un plato de comida favorita y quieres saber si un nuevo chef puede preparar algo similar. Entonces, le das un test con una receta específica para ver cómo lo hace.

**Puntos Clave:**
1. Se utiliza para evaluar habilidades o conocimientos.
2. Puede ser escrito, oral o práctico.
3. Ayuda a tomar decisiones o clasificar a las personas.
