要编写一个计算阶乘的函数，我们可以使用Python语言来实现。以下是一个简单的阶乘函数，它接受一个整数作为输入，并返回该整数的阶乘：

```python
def factorial(n):
    if n < 0:
        return "Factorial not defined for negative numbers"
    elif n == 0:
        return 1
    else:
        result = 1
        for i in range(1, n + 1):
            result *= i
        return result

# 测试函数
print(factorial(5))  # 应该输出120，因为5的阶乘是5 * 4 * 3 * 2 * 1 = 120
```

这个函数首先检查输入的数是否为负数，因为负数的阶乘在数学上是没有定义的。然后，它检查是否为0，因为0的阶乘定义为1。对于正整数，函数使用一个循环从1乘到n，计算出阶乘的结果。
