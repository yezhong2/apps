Para probar un código, es importante diseñar una serie de casos de prueba que cubran diferentes escenarios y posibles entradas. Aquí tienes 5 sugerencias específicas para crear casos de prueba:

1. **Prueba de entrada válida**: Proporciona datos esperados y asegúrate de que el código maneje correctamente los valores correctos.
2. **Prueba de entrada nula**: Envía datos nulos o vacíos y verifica que el código maneje estos casos sin errores.
3. **Prueba de entrada inválida**: Introduce datos que no deberían ser aceptados y observa cómo el código los maneja (por ejemplo, caracteres no permitidos, números negativos en un contexto positivo).
4. **Prueba de rendimiento**: Utiliza datos grandes y complejos para evaluar la eficiencia y velocidad del código.
5. **Prueba de tolerancia a fallos**: Introduce errores intencionados en el código (como divisiones por cero) y verifica que el sistema maneje estos errores de manera adecuada.
